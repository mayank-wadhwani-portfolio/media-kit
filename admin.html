Connect your GitHub repository

Use a GitHub fine-grained personal access token with access to this repository and Contents: Read and write. The token is used only in this open tab and is never saved in local storage.

Create one at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Limit it to this repository and grant Contents read/write permission. Never paste the token into chat or commit it to GitHub.

Security note: This page does not save your GitHub token, but the page itself is accessible at its URL. Use your own device, grant the token access only to this repository, revoke it from GitHub when you no longer need it, and never use this page on a shared computer. The token is sent directly from your browser to GitHub's API.
